# AI Prompt Engineering Portfolio

This repository showcases my applied work in designing, testing, and documenting prompt systems for large language models (LLMs). The focus is on **scalable, repeatable prompt frameworks** used for content generation, localization, tone control, and clarity — not one-off experiments.

I bring over two years of hands-on prompting experience across multiple models, with a background in technical writing and customer education. My approach treats prompts as systems: structured, documented, evaluated, and continuously improved.

## Areas of Focus
- Prompt system design for text generation
- Prompt libraries and reusable templates
- Tone, voice, and style control
- Localization-aware prompting
- Context layering and constraint-based prompts
- Prompt iteration and evaluation criteria
- Documentation of prompt frameworks and best practices

## Models & Tools
- Claude (Anthropic)
- OpenAI (GPT family)
- Grok
- DALL·E (visual prompting)
- Markdown-based documentation workflows

## Repository Structure
Each section includes prompt examples, iteration notes, and reasoning behind design decisions.
